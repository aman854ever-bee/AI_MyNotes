# ADR 0001: Product name is MyNotes

Date: 2026-09-11 · Status: Accepted

## Context
The source PRD (`AI_Work_Companion_PRD.md`) was written under the title
"AI Work Companion", codename "WorkMate AI". Aman introduced the product to
build as **MyNotes**.

## Decision
Use **MyNotes** everywhere going forward — repo name, package names, UI
copy, docs. The PRD's vision, principles and requirements are otherwise
unchanged; only the name is superseded.
